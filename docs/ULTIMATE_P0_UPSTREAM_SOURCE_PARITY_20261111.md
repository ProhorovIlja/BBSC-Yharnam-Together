Do not close #73 or treat #137 save-ACK, #35 item lots or #22 HomeWorlds as solved. Refer to [B88 detailed report](ULTIMATE_BATCH_88.md).

## Confirmed source details

- B64 `HomeWorlds` in Ultimate **is stronger in one area** than the #554 reference: it refuses to silently evict the oldest home world at the 17th entry. That is **not** a substitute for hooking live `ApplyTeamWorldOnLoad`.
- Ultimate `SetGuestWorldChanges` already has extra metadata write retry/atomicity work. Porting #553 means adapting to that path, not overwriting our entire source file.
- `SetGuestPickedFlags` already owns a `guest_picked_mutex` and uses the game's native event-flag setter. A repeated call must not hold that mutex across an outer lock or block the game thread; upstream's 2026-11-10 test is useful but not sufficient for our live merged tree.
- `KeepGuestProgress` runs under `IsPartyGuestRole` and `GuestProgressInterval`; source-level checks must assert game role, slot/generation baseline reset and reapply order. Test new hunter in reused slot and map-change behavior.
- P0 #35 delayed boss/NPC lot is separate from P0 #137 phantom-earned key items. Do **not** classify one as fixed because the other has a passing test.
