# Bloodborne retail intake: identify first, verify separately

Folder names, storefront labels, disc markings and SFO TITLE_ID are different identifiers. Use the selected directory's sce_sys/param.sfo for identification. Preserve the observed ID; do not turn disc or country labels into executable profiles.

Initial catalog leads, not a support list: CUSA00900 (North American original), CUSA03173 (European GOTY), CUSA00299 (Japanese original; PCJS-53005 disc label), CUSA00207, CUSA00208, CUSA00601. PCJS-53012 is listed for a Japanese Old Hunters Edition disc; verify its actual SFO on a local fixture instead of inferring an alias. Source: https://serialstation.com/games/763bcca3-8039-4791-9ce6-fe43272e1eb8

A contribution can start with only the SFO title ID, APP_VER, and locally computed SHA-256 for the extracted executable and required modules. Do not request packages, binaries, keys, saves, or absolute paths. A report is a lead, not a trusted allowlist entry. Verify clean retail provenance, match base and update, and test assets/DLC separately from code. Equal verified executable and module fingerprints can share a code profile; unequal hashes require investigation, not an automatic alias or rejection as piracy.

Support states: cataloged; metadata observed; code fingerprint verified; native launch verified per OS; co-op verified per compatible build pair. Start with the verified copy available to the project. A new region does not delay known profiles. In the native mode no PS4 executable is accessible at Play time after local preparation; preserve the old loader as a separately selected mode.
